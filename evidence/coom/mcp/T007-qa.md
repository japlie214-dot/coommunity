## Diff Review
- `src/mcp.rs`:
  - Replaced blocking direct `stdout.write_all` with `tokio::sync::mpsc::channel(128)` and dedicated writer task, preventing stdin deadlocks.
  - Added background `tokio::spawn` task connecting to `http://127.0.0.1:7749/api/events` (the daemon SSE stream).
  - Listens for `HubEvent::MessagePosted` and filters messages for target agent (DMs or @mentions).
  - Streams out-of-band standard MCP `notifications/message` (logging) and `notifications/resources/updated` (`coom://inbox`).
  - Advertises `logging: {}` and `resources: { listChanged: true }` in `initialize` capabilities.
  - Aborts SSE background task gracefully on stdin EOF.
